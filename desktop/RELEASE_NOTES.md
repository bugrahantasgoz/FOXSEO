## FOXSEO 0.1.0 – Demo

İlk Windows sürümü. Ücretsiz, kişisel SEO aracı.

### Kurulum

1. Aşağıdan **FOXSEO-Kurulum-0.1.0.exe** dosyasını indir ve çalıştır.
2. Windows "bilgisayarınız korundu" derse **Ek bilgi → Yine de çalıştır** (uygulama imzasız olduğu için).
3. Masaüstündeki **FOXSEO** simgesiyle aç. İlk açılış bir dakika kadar sürebilir.

Node.js veya başka bir program kurmana gerek yok.

### Bu sürümde

- Site denetimi (kırık linkler, başlıklar, meta açıklamalar, sitemap, robots.txt…)
- Hız ölçümü (Google PageSpeed Insights, ücretsiz API anahtarı gerekir)
- Google Search Console ve Google Analytics bağlantısı
- Anahtar kelime fikirleri ve backlinkler (Bing Webmaster Tools, ücretsiz API anahtarı gerekir)
- Claude bağlantısı (MCP): `http://localhost:3001/mcp`

API anahtarlarını menüden **FOXSEO → Ayarlar (API anahtarları)** ile ekle, sonra **FOXSEO → Yeniden başlat**. Anahtarların nasıl alınacağı: [KURULUM.md](https://github.com/bugrahantasgoz/FOXSEO/blob/main/KURULUM.md)

### Bilinen eksikler

- Demo sürümdür, hata görürsen bildir.
- Claude bağlantısındaki bazı araçlar (rakip analizi vb.) henüz kapatılmadı ve hata verebilir.
